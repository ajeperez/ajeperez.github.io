## Adding a PDF locally

If you wish to add any of the above PDFs locally for direct download:

1. Download the PDF from the Zenodo DOI
2. Rename it following the convention: `PEREZ-2026X-short-title.pdf`
3. Place it in this `documents/` folder
4. Update `/index.html` to replace the `View on Zenodo` button with a `Download PDF` button (see existing examples in PEREZ 2026a, 2026b, 2026f)
